# 天鹅到家 · 做饭钟点工下单助手

通过对话帮你完成天鹅到家上门做饭钟点工的预约下单，从说出需求到支付完成，全程在对话里搞定。

# 能做什么

**一句话下单**

告诉助手你想在哪里、什么时候需要阿姨上门做饭，它会自动匹配地址、查询可约时段、生成订单，你确认后即可支付。

**智能理解你的需求**

你不需要按固定格式说话。说"明天中午"它知道是 11:30，说"3个人吃饭"它知道安排 3 小时服务，说"少油少盐"它会自动备注给阿姨。

**最少追问**

能从你的话里推断出来的信息不会再问，规格默认 3 小时不需要你选，只有真正缺少的信息才会问你一次。

---

# 不能做什么

- 不能下单保洁、月嫂、搬家等其他天鹅服务，只做"上门做饭钟点工"这一个品类

- 不能查询已有订单状态或取消订单

- 不能指定某个阿姨

- 不提供菜谱推荐或烹饪指导

---

# 怎么用

## 说出你的需求就行

- "我想找个做饭阿姨"

- "明天中午帮我找个做饭的到望京花园3号楼"

- "后天晚上，4个人吃饭，喜欢川菜，少辣"

助手会根据你提供的信息量自动调整流程：信息全就直接出订单预览，信息少就一步步引导你补充。

## 首次使用需要授权

助手会发一个授权链接，点击完成授权后回复"已授权"即可继续。授权是为了获取你的服务地址和下单能力。

## 确认后才会下单

助手会先展示一张订单预览卡片（包含地址、时间、规格、费用），你说"确认"之后才会生成订单。不确认就不会产生任何费用。

确认前你可以随时修改地址、时间、规格；确认支付后如需修改，需要取消订单重新下单。

# 常见问题

**包含买菜吗？**

不含。如果坚持让阿姨代买菜，买菜时间计入服务时间，做菜时间会相应减少。

**能照顾老人孩子吗？**

不能。做饭钟点工只负责上门烹饪。

**下单后能改时间/地址吗？**

需要取消订单后重新下单。阿姨接单后取消会扣违约金（12 小时外取消全退，2\-12 小时退 80%，2 小时内退 60%）。

**下单后多久要支付？**

订单生成后需要在 10 分钟内完成支付，超时订单会自动取消。

**阿姨什么时候上门？**

阿姨会在你预约的服务时间准时上门。下单时需要提前至少 2 小时预约。
